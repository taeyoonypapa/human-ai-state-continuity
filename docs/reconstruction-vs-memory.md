# Reconstruction vs. Memory

Memory retrieval asks:

> What happened before?

State reconstruction asks:

> Given what happened before, what is the correct current actionable state now?

These are different questions.

A system may retrieve most prior facts correctly while still constructing the wrong current state.

```text
Recovered:
- completed analysis
- confirmed decision

Missed:
- unresolved contradiction
- required follow-up step
```

The retrieval was partially successful.

The state reconstruction was not.

```text
Historical context ≠ Current actionable state
```

Historical context is evidence used to reconstruct state.

It is not automatically the state itself.

A further distinction is important:

```text
No reconstructed task
        ≠
Evidence of completion
```

The absence of remembered work should not be treated as positive evidence that no work remains.

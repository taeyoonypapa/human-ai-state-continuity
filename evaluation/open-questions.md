# Open Questions

External critique is especially useful on the following questions.

1. Is an explicit Current Work State necessary, or can retrieval plus summarization provide equivalent continuity?
2. What is the minimum information, and the simplest architecture, that meaningfully reduces false current-state reconstruction?
3. How should unresolved work be represented so that it is difficult to silently lose?
4. How should contradictions between conversational reconstruction and external state be resolved, and when should uncertainty be preserved instead of forcing a single state?
5. What positive evidence should be required before a workstream is considered complete? Can this be made robust, or detected, without a dedicated work-state representation or completion-validation step?
6. How much state should be externalized before the maintenance burden outweighs the benefit?
7. What other long-horizon continuity failures are more dangerous than simple memory loss, including the reverse failure of stale open issues?
8. What existing systems or research already address this problem under a different name?
9. How can the externalized state itself be checked for completeness and freshness?

Critical counterexamples and simpler alternatives are especially welcome.
